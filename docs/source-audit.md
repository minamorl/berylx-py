## Observable core contract

Focus retains a root and immutable path. `at` extends path without access; `get` traverses and throws KeyError on missing path; supplied default catches traversal failures, not just null values. `fetch`, `maybe`, `present`, `required` preserve missing-vs-present-null distinction. `required` returns Ok of the same focused object or Err retaining path/root. `set`/`update`/`put` return a new ROOT focus, path empty. Missing/null map branches are constructed as maps. Arrays use numeric-index semantics; class instances with `with(patch)` support immutable updates. Root extraction exposes the complete root, not the current path value.

Fixed Focus defensively copies/deep-freezes plain records and arrays on construction/update, preserving cycles; already-deeply-frozen structures may share identity; repeated mutable acyclic children are separately copied. Nonplain class instances (Date, Map, Set, etc.) retain identity. Python must explicitly state its equivalent supported domain and behavior for cyclic containers, identity, lists/tuples, missing sentinel, numeric/string indexes, JS prototype keys and arbitrary objects.

Workflow Ok carries Focus; Err carries partial Focus plus BerylxError. They are distinct from Darkcore.Ok/Err. ResultOps.normalize preserves existing envelopes, otherwise wraps raw value in Focus/Ok. Both ResultOps.map and bind normalize callback output (map intentionally flattens envelopes too). Err.pipe returns itself without invoking callback. Ok.pipe calls node directly. Structured errors retain code/message/cause/failedNode/trace/parallelErrors/metadata/fatal. withContext merges metadata, replaces explicitly supplied context fields; prependTrace also supplies failedNode if missing. unwrap returns cause unless nullish; Err.unwrap throws it. Task catches ordinary exceptions at the input Focus and supplies failedNode/name trace; an explicitly returned Err retains its partial Focus and gets task context only if failedNode was absent. ControlSignal must escape unchanged. Exceptions in predicates/handler dispatch are not generally transformed into Err.

Sequence flattens nested sequences, binds steps in order, forwards Err over normal steps without execution, but allows later Catch boundaries to recover. Catch on Ok or standalone Catch is identity; default excludes fatal Err, option fatal=true includes it. Rescue handles any Err, including fatal. Recovery receives cause preferentially, else BerylxError, and partial Focus. Task recovery and block recovery under real interpreter both attach original error serialization in `metadata.rescuedError` when recovery fails. Low-level legacy EffectTree.recover helper differs: direct RescueBlock path bypasses that attachment. Specify whether this helper is exposed.

Root owns committed state: execute via State/Flow/EffectTree and commit only Ok automatically. Err partial state never auto-commits. Explicit commit(Focus/Root/Ok/Err) replaces from carried Focus; commit(raw nonarray object) deep-merges; scalar/array replaces. Subscribers immediately receive snapshot, then commits until unsubscribe. history contains only commits, kept in the same list; historyLimit omitted=unbounded, 0=none, positive integer=latest N; negative/fraction/NaN/infinity invalid. Subscriber errors escape after state/history mutation. State.and accumulates without execution; State.call uses explicit or pending node, throws if absent.

## Parallel and merge

All branches see SAME immutable base. Fixed default reducer is STRICT THREE-WAY merge. Nested Parallel nodes flatten irrespective of their original reducer/mode. Outer par/reduce preserve outer mode/reducer. Sync interpreter runs every branch in declaration order, collects thrown values, then rethrows first thrown by branch order. Async interpreter starts every branch and waits for allSettled, then rethrows first rejected by declaration order. Thus short_circuit describes envelope selection, NOT cancellation or stopping branch execution. If no thrown values: first Err wins in short_circuit; accumulate yields parallel_failed with first Err focus/cause/failedNode/trace and all errors in declaration order. No successful branch merge occurs if any Err.

Successful reducer fold starts with base and folds branch states in declaration order. Exactly-three-parameter reducers receive base. Ordinary reducer throws yield Err at BASE, failedNode/trace parallel; ControlSignal escapes. keepLeft therefore keeps base; keepRight ultimately picks last branch. deep performs right-biased recursive object merge, arrays/scalars atomic; root nonobjects coerce to empty object. Explicit deep can erase previous branch changes because later full snapshot includes old values. Strict compares changed-vs-base: unchanged side yields other; equal simultaneous changes accepted; incompatible simultaneous changes throw merge_conflict with path,left,right,base metadata. It recursively merges objects where base is object/missing. Missing-key handling first adopts the present side: deletion semantics are NOT a full deletion-aware three-way merge; avoid falsely claiming arbitrary deletions. Base-only absent-on-both key can leak internal MISSING. Parallel strict is NOT Timeline concurrent commit merge (see below). Restrict equivalence/property domains or document these edges.

## Actual monad and interpreter substrate

Darkcore Effect is a shallow immutable tagged record: closed pure has payload/value and no continuation; open op(tag,payload,DECODER) retains inspectable payload and typed resume. Payload contents remain mutable. `pure` tag is reserved. Decoder runs on handler response before bind continuation. bind on pure immediately calls continuation; bind on open op grafts structure without interpreting effects. fold/foldAsync loop over steps, dispatch by tag, then apply onReturn at terminal. Missing handler/decoder exceptions propagate. step inspection is effect-free and continuation reusable. Loop interpretation does not alone guarantee arbitrary left-associated bind chains stack-safe (nested closures can overflow); test deep right-associated tree and document/engineer stronger guarantee if supplied.

Maybe Just/Nothing, Either Right/Left, Darkcore Result Ok/Err, State, Validation are separate categories. fmap derives from pure+bind and ap from bind+fmap except Validation.ap deliberately accumulates failures (ordered concatenation). Validation.bind short-circuits. Thus accumulating ap is not the ap induced by Validation's bind; never assert that coherence law. Maybe.fromNil maps null/undefined to Nothing, but 0/false remain Just. State represents s -> [value,newState], with get/put/modify and sequential state threading. Result.try\_ captures ordinary exception message as Err. Ruby additionally mixes fmap/ap into Effect and exposes global step/Done/Pending; TS Effect only exposes bind/seq/step. Python additions beyond TS should be labeled.

EffectTree compiles tasks/parallel/branch/rescue/recovery to `berylx_task`, `berylx_parallel`, `berylx_branch`, `berylx_rescue`, `berylx_recover`; payload is [node,Focus] (recover [Rescue|Catch,Err]). Built-in payload decoders reject wrong shape/types; all handler results must be workflow Ok/Err. Sequence compiles through Effect.bind; result short-circuit algebra is workflow continuation logic, not Darkcore.bind. Application effects cannot collide with reserved tags. realHandlers propagates same current map through nested subtrees/recovery; around wraps both builtins/custom effects and passes wrapped map through all nesting. Flow/State/Root.call accept supplied handlers. Perform rejects pure/missing tag and directly dispatches current map.

Task callbacks declaring >=2 parameters receive Perform; other callbacks receive exactly one arg. Recovery >=3 receives Perform; otherwise exactly two. Python arity translation must be deliberate (defaults/varargs/bound methods). AsyncTask synchronous call throws; call_async awaits callback and captures ordinary exceptions. Sync Task under async interpreter remains synchronous; async Perform return values must be awaited by user async callback. Recovery block stays synchronous even under async interpreter; use AsyncTask recovery for await. Dry-run swaps handlers, skips task callbacks and all custom effects, enumerates selected branches (predicates DO run), all parallel branches, only rescue body; does not model failure paths. Workflow wrapper.call unwraps body, but passing wrapper itself to EffectTree compile/run is unsupported upstream.

IOEffects are typed tagged effects for say/warn/ask/read/write/append/delete/exists/list_dir/getenv/now/rand/shell. Concrete response decoders and string-pair payload validation matter. VirtualWorld logs say,warn,ask,read,write,append,delete,shell only; exists/list/env/time/rand don't log. write/append log path not data. Directory listing returns all relative descendants, not only immediate children. Missing shell -> empty string; absent asks/env -> undefined in JS; random cycles supplied sequence modulo n. Real IO uses OS, UTF-8 text, shell command execution; Python errors/time types differ and should be listed. Dual-run one SAME program under virtual/real handlers to prove interpretation independence.

## Timeline (separate scheduler domain present in fixed upstream)

Timeline.forExecution shares one Timeline by token identity; same token with another clock rejects CLOCK_CONFLICT. Draft registers ai/user/human-login tasks and time origins; issue once snapshots and locks draft but does not execute. start once starts evaluation. States pending/running/waiting/completed/failed; unknown task references rejected by identity. Human tasks become waiting when ready and require matching human-completed event; login wait effects can activate predeclared login tasks and await a future without blocking unrelated work. Predicates observe events/state and compose all/any. AI executes once unless recurring(eventType); recurring cursor consumes each matching event exactly once after predicate readiness.

Scheduler runs ready work concurrently, processes completions/events while others wait. emit during an active pass records event/state and queues reevaluation but returns without waiting (avoids runner-await-emit deadlock). advance during active run waits for a new scheduler pass/newly triggered work, not preexisting login waiters. First fatal AI failure yields TimelineError TASK_FAILED, fails running/waiting tasks, rejects human waiters, and prevents late Root commits. Pending work is not all marked failed. Observations return event-list snapshot but live state lookup closures. Errors serialize code,message,details,26-character ULID trace_id.

Beat due timestamp from +beat\*60000/bpm; positive finite BPM, nonnegative beat, optional positive recurring beat. Calendar interval minute/hour/day; UTC cron fields validated/sorted/deduped, dayOfMonth AND dayOfWeek, minute resolution and 40-year search bound. Due occurrences append by origin declaration order (not global timestamp order); recurrence backlog emitted on advance exactly once. Keyframes sorted, same timestamp replacement, linear interpolation, endpoint clamping, finite values required.

BerylxTimeline binds Root identity to Timeline; runs workflows through async EffectTree.aroundAsync; emits task-started/completed/failed for each executed leaf including nested recovery. Retains Result by timeline task; Err never commits and raises scheduler TASK_FAILED. Concurrent successful commits use distinct deletion-aware three-way merge of current/completed/base: unchanged wins opposing change, equal concurrent values accepted, recursive plain-object merge, deleted keys omitted, deletion-vs-update conflict, scalar/array replacement allowed if other side unchanged. Late completions after fatal plan failure cannot commit. This is materially different from Merge.strict and must not share its missing-key policy blindly.
